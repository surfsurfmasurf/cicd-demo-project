Tranquil Swirl

Code Golf 스타일의 짧은 코드로 구현한, 끊임없이 변화하는 소용돌이 패턴입니다.

🎨 작품 해설

이 작품은 수만 개의 점들이 수학적 함수에 의해 춤을 추듯 움직이며 형상을 만들어냅니다. 삼각함수(sin, cos)의 중첩과 시간 변수(t)의 변화가 결합되어, 마치 살아있는 유기체나 은하계의 소용돌이 같은 패턴을 생성합니다.

매 프레임마다 20,000개의 점을 다시 그리며, 배경을 지우고 다시 그리는 과정을 통해 애니메이션 효과를 만들어냅니다. Code Golf(코드 골프) 기법을 사용하여 극한으로 압축된 수식으로 복잡한 시각적 효과를 구현했습니다.

⚙️ 코드 분석

  • 초압축 수식:
    d=mag(...)**2/79+1
    점들의 거리와 분포를 결정하는 핵심 공식입니다.
  • 운동성 (Motion):
    sin(d*d+e/9-t)
    시간 t가 흐름에 따라 파동이 퍼져나가는 듯한 움직임을 만듭니다.
  • 극좌표 변환:
    point((q...)*sin(c)+200, (q...)*cos(c)+200)
    계산된 값을 극좌표계(반지름과 각도)로 변환하여 원형의 소용돌이 형태를 구축합니다.

💻 Source Code (Original Golf)

a=(y,d=mag(k=9*cos(y*2),e=y/8-12)**2/79+1)=>point((q=79-e*sin(k)+k/d*(8+4*sin(sin(d*d+e/9-t))))*sin(c=d/2-cos(d*2)/5-t/16+i%2*3)+200,(q+40)*cos(c)+200)
